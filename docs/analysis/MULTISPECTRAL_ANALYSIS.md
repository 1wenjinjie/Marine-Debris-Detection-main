---

## 🎯 核心问题分析

### 1. **为什么人眼看不清？**
- **分辨率限制**: 10米像素下，海洋垃圾（如塑料瓶、渔网碎片）只有几米大小
- **光谱局限**: 人眼只能看到RGB波段（400-700nm），无法感知近红外信息
- **环境干扰**: 海面波纹、阳光反射、云影等干扰人工识别

### 2. **为什么机器看得清？**
- **多光谱优势**: 利用NIR波段（近红外）区分水体vs漂浮物
- **光谱特征**: 不同材料有独特的光谱反射曲线
- **算法能力**: 深度学习能学习复杂的多通道特征组合

---

## 📊 多光谱对比分析

### RGB真彩色 (人眼视角)
```
❌ 局限性：
- 海洋垃圾与海水颜色相似
- 阳光反射干扰识别
- 小目标在10米像素下模糊不清
- 人工标注准确率低
```

### NIR近红外 (机器视角)
```
✅ 优势：
- 水体强烈吸收NIR光，显示为暗色
- 漂浮物（塑料、木头）反射NIR，显示为亮色
- 对比度高，目标突出
- 自动检测准确率高
```

### 假彩色合成 (NIR-R-G)
```
✅ 增强效果：
- 植被显示为红色（高NIR反射）
- 水体显示为蓝色/黑色（低NIR反射）
- 增强水陆边界和漂浮物
- 类似专业遥感软件的显示效果
```

### NDVI植被指数
```
✅ 生物识别：
- 绿色 = 浮游生物/海藻（高植被指数）
- 红色 = 纯水体（低植被指数）
- 黄色 = 海洋垃圾（中等指数）
- 区分有机vs无机漂浮物
```
