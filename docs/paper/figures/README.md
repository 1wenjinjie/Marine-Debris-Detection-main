## 呈现规范（统一约定，2026-05-20）

paper 全部图表遵守：

- **主指标**：Marine_Debris AP50 / F1 — 故事中心，每张比较图都要出现
- **次指标**：mAP50 (all classes) — 写图注 "Marine_Debris dominates" 避免被误读为类别均衡
- **per-class 图 / 表只包含有 GT 的类**：v1 test 上是 Marine_Debris (103)、Natural_Organic (11)、Ship (4)、Foam (1)；Dense_Sargassum、Sparse_Sargassum、Wakes 在 v1 test 上 0 GT，AP 数字是噪声，**禁止上图**
- **imgsz=1024 描述**：图注一律写 "letterbox up-sampling to 1024 (native tile 256×256)"，绝不出现 "higher resolution sensor input"
- **置信度**：误差棒一律 3-seed mean ± std；非 3-seed 数字加 `*` 角标说明
