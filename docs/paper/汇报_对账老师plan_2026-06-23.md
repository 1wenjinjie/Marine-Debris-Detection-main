## 3. 模型与实验对账（v1 honest 线真实数字）

老师要求：YOLOv8 + CBAM / BiFPN / EIoU / Full 四组对比。实际：升级到 **YOLOv11n**（老师允许"尽量最新版"），四组全部 3-seed 完成。

**honest 线消融（imgsz=512, 3-seed mean±std）：**

| 模型 | mAP50 | Best F1 | Debris AP50 |
|---|---:|---:|---:|
| Baseline | 0.313 ± 0.038 | 0.409 ± 0.022 | 0.492 ± 0.056 |
| +CBAM | 0.258 ± 0.014 | 0.359 ± 0.041 | 0.525 ± 0.047 |
| +BiFPN | 0.300 ± 0.059 | 0.406 ± 0.029 | 0.559 ± 0.023 |
| +EIoU | 0.299 ± 0.036 | 0.410 ± 0.056 | 0.524 ± 0.057 |
| Full | 0.232 ± 0.014 | 0.335 ± 0.006 | 0.540 ± 0.018 |

**imgsz=1024 honest 线（3-seed）：**

| 模型 | mAP50 | Best F1 | Debris AP50 |
|---|---:|---:|---:|
| baseline | 0.342 ± 0.011 | 0.427 ± 0.048 | 0.607 ± 0.022 |
| **bifpn** | **0.350 ± 0.031** | **0.479 ± 0.037** | 0.576 ± 0.045 |
| eiou | 0.336 ± 0.031 | 0.455 ± 0.015 | 0.563 ± 0.035 |
| cbam | 0.252 ± 0.011 | 0.360 ± 0.004 | 0.609 ± 0.040 |
| full | 0.230 ± 0.014 | 0.343 ± 0.030 | 0.610 ± 0.054 |

**诚实结论（要点）：**
- 单看 imgsz=512：四个结构改动 **均未稳定提升** baseline（提升幅度在 std 内）。这是有用的 negative result。
- **BiFPN × imgsz=1024 协同**：Best F1 从 baseline+1024 的 0.427 提升到 0.479（约 +12%），是 honest 线相对最明显的正向贡献；但 Debris AP50 反而略低（0.576 < 0.607），需诚实呈现，不夸大。
- FPS 已测（`v1_ablation_fps_bench.py` / `v1_imgsz1024_fps_bench.py`）。

**部署指标（自加，更严格）：** BiFPN+1024 seed-0，per-tile instance 级、τ=0.25、IoU≥0.5 → **F1=0.604**（P 0.581 / R 0.630），见 `v1_test_per_tile.csv`。

## 5. 自加内容（老师 plan 未要求，但构成项目核心价值）

1. **GT 泄露发现 + 4-cell 归因（最重要）：** 发现原强结果由 GT 泄露撑起——(a) scene-level split 泄露，(b) 真正主因：ch7 曾是从 GT mask 派生的 oracle prior，把标签泄进输入。对照见 leaky vs honest baseline：F1 0.740 → 0.409、Debris AP50 0.856 → 0.492。诚实 ch7 改为 NDWI-inverse 物理先验（不含 GT）。
2. **诚实再评估协议：** scene-clean split + native-256 control + unetprior 反例，定位"imgsz=1024 有效"的真实机制是特征图 cells 增多，非传感器分辨率。
3. **置信度校准：** Platt scaling（a=0.4078, b=-0.5091），held-out test ECE 0.051→0.029（1.75×），并显式区分 in-sample(val 3.5×)/held-out。由此定出部署阈值 τ=0.25。
4. **非 ML 物理基线对比：** FDI / NDWI-inverse，量化 YOLO 相对纯物理指数的增益。
5. **Finding D（跨范式对比）：** 同一 honest split 上 U-Net instance recall ≈0.59 vs YOLO ≈0.15，揭示 detection 框架对 sub-4px 目标的硬天花板。
6. **PKD 知识蒸馏：** 早期主线，已搁置，作为 negative finding / upper-bound 分析保留。

## 6. 老师 plan 中需偏离/降级的项（技术理由）

> 说明：以下偏离均出于数据真实特性，非随意改动；建议在汇报中主动说明，体现严谨。

1. **裁剪 512×512** → MARIDA 原始 patch 就是 native 256×256，imgsz 是 letterbox 上采样。论文措辞需写"特征图 cells 增多 / 让小目标 box 落在 P3 head 设计区间"，不能写"更高分辨率"。
2. **RGB+NIR 四通道** → 加 SWIR(B11/B12) 共 6 通道对水体/碎片区分更有效，是合理增强。
3. **色彩抖动增强** → 光谱通道不是 RGB 颜色，hsv 抖动无物理意义，已禁用。
4. **70/20/10 随机划分（最关键）** → 随机划分会让同一景的 tile 同时进训练/测试 = scene-level leakage。必须改 scene-clean split。这是 plan 里需纠正的方法学缺陷。
5. **YOLOv8 + COCO pretrained** → 升级 YOLOv11n（plan 允许）；6/7 通道输入无法直接套 3 通道 COCO 权重，改 clean init。
6. **Roboflow UAV fine-tune** → RGB UAV 不能直接 fine-tune 6ch S2 模型；只能作独立 RGB 分支做跨域验证，"fine-tune 提升小目标"的设想不适用。
7. **图10 时间趋势线** → MARIDA 是稀疏 scene（<100 tile、跨多年），非连续时间序列，画趋势线会误导，改描述性按月计数。
8. **图11 CMEMS** → optional；同样受稀疏 scene 限制，物理相关性意义有限，可放附录或不做。
9. **表4 检测数量×风速/流速相关性（最不成立）** → 稀疏 scene 无法支撑相关性统计，做出来会被审稿人质疑造假。建议 **降级为描述性环境因子说明或直接删除**。
