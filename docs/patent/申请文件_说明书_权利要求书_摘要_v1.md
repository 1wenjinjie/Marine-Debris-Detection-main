# 一、权利要求书

**1.** 一种海洋漂浮垃圾多光谱检测方法，其特征在于，包括如下步骤：

S1、获取海面的多光谱遥感影像，所述多光谱遥感影像包含多个光谱波段，所述多个光谱波段至少包括绿光波段和近红外波段；

S2、由所述多个光谱波段中的至少两个波段，按预设的确定性映射计算得到一物理先验通道，所述物理先验通道与所述光谱波段具有相同的空间尺寸，其每个像素值表征该像素属于水面漂浮物的先验可能性，且所述确定性映射的计算不依赖任何人工标注；

S3、将所述多个光谱波段与所述物理先验通道沿通道维度拼接，构成多通道输入张量，并对所述多通道输入张量的各通道分别进行归一化；

S4、将归一化后的所述多通道输入张量输入预先训练的卷积神经网络检测器，由所述检测器的卷积层将所述光谱波段与所述物理先验通道联合卷积并提取特征，输出海洋漂浮垃圾的实例级边界框及其对应的置信度。

# 二、说明书

## 一种海洋漂浮垃圾多光谱检测方法、装置及存储介质

### 技术领域

本发明涉及遥感图像处理与目标检测技术领域，尤其涉及一种基于多光谱卫星影像、融合水体物理光谱先验的海洋漂浮垃圾检测方法、装置及计算机可读存储介质。

### 背景技术

海洋漂浮垃圾（含塑料碎屑、漂浮藻类、泡沫等）的大范围、快速、自动化监测是海洋环境保护的重要需求。卫星多光谱遥感（如 Sentinel-2）具有覆盖广、重访快、波段丰富的优势，是该监测任务的重要数据源。

现有技术主要有两类。第一类是光谱指数阈值法：针对水面漂浮物已提出多种物理光谱指数，如浮游碎屑指数 FDI、归一化水体指数 NDWI、浮游藻类指数 FAI 等；其做法是对影像逐像素计算指数值并设定阈值，将超过阈值的像素判为漂浮物。该类方法对噪声、薄云、太阳耀斑及海况变化敏感，固定阈值跨场景泛化能力差，且只能输出像素级二值掩膜，无法给出目标级（实例级）的边界框与计数。

第二类是通用深度学习目标检测器，如 YOLO、Faster R-CNN 等。此类检测器面向自然图像的三通道彩色输入设计，难以直接、充分地利用多光谱影像中近红外、短波红外等对漂浮物可分性贡献最大的波段；并且海洋漂浮垃圾在卫星影像中目标极小、与海面背景对比度低，检测器仅凭原始光谱波段自行学习，在样本少、类别不平衡的条件下难以收敛到稳定有效的判别特征，召回率低；此外检测器输出的置信度往往严重失真，难以直接作为概率使用。

因此，需要一种能够把水体物理光谱先验有效融入检测网络、对多光谱影像直接给出实例级漂浮垃圾检测、并输出可信置信度的方法。

### 发明内容

**（一）要解决的技术问题**

针对海面漂浮目标小、弱、样本少、类别不平衡、置信度失真的问题，本发明要解决的技术问题包括：如何将水体物理光谱先验作为输入与原始波段联合送入卷积神经网络，对多光谱卫星影像直接进行实例级漂浮垃圾检测；以及如何输出经校准的可信置信度。

**（二）技术方案**

为解决上述技术问题，本发明提供一种海洋漂浮垃圾多光谱检测方法，包括：获取包含绿光波段与近红外波段在内的多光谱遥感影像；由其中至少两个波段按确定性映射计算一物理先验通道，该通道每个像素值表征该像素属于水面漂浮物的先验可能性，且不依赖人工标注；将光谱波段与物理先验通道沿通道维拼接构成多通道输入张量并逐通道归一化；将其输入卷积神经网络检测器，由卷积层将光谱波段与物理先验通道联合卷积，输出漂浮垃圾的实例级边界框及置信度。

进一步地，所述物理先验通道由归一化水体指数的反向映射构造，即 P = clip((1 − NDWI)/2, 0, 1)，NDWI = (G − N)/(G + N + ε)；也可由 FAI、PI 等可由所述光谱波段计算的漂浮物敏感指数或其组合归一化构造。

进一步地，检测器颈部采用加权双向特征金字塔网络融合多尺度特征；将输入按保持长宽比的填充方式上采样至设定尺寸，使目标尺度落入浅层检测头的设定响应区间；并对输出置信度施加单调校准 p = sigmoid(a·logit(s)+b)，校准参数由验证集拟合后冻结。

本发明还提供实现上述方法的装置及存储介质。

**（三）有益效果**

本发明将确定性、无需人工标注的水体物理光谱先验作为输入通道与原始光谱波段联合送入卷积神经网络，使网络在端到端训练中即可利用领域物理知识，对多光谱卫星影像直接输出实例级（边界框）的海洋漂浮垃圾检测结果，克服了传统光谱指数阈值法只能输出像素掩膜、无法给出实例与计数的局限。在公开的 Sentinel-2 海洋漂浮垃圾基准数据集、采用场景级划分（避免数据泄漏）的测试集上，本方法对极小目标漂浮垃圾给出可用的实例级检测能力；通过对输出置信度的单调校准，显著降低了置信度的期望校准误差，使输出概率可作为可信依据。

### 具体实施方式

为使本发明的目的、技术方案更加清楚，下面结合附图和实施例进行详细说明。以下实施例仅用于解释本发明，而非限定本发明。

**实施例一（完整检测流程）**

参见图 1。

步骤 S1，获取 Sentinel-2 L2A 多光谱遥感影像并裁切为瓦片，每个瓦片为高 H、宽 W 的多波段数组，本实施例取六个光谱波段 B4、B3、B2、B8、B11、B12，分别对应红、绿、蓝、近红外及两个短波红外波段，数据为浮点型表面反射率。

步骤 S2，由绿光波段 B3 与近红外波段 B8 计算物理先验通道 P：NDWI = (B3 − B8)/(B3 + B8 + ε)，P = clip((1 − NDWI)/2, 0, 1)，其中 ε 取 1×10⁻⁶。其物理依据为：纯水体在近红外波段强吸收，NDWI 较高，P 趋近 0；漂浮物在近红外的反射高于绿光，NDWI 为负，P 大于 0.5。由此 P 在漂浮物处取高值、纯水处取低值，构成像素级漂浮物先验，且仅由波段确定性算得，不依赖人工标注。

步骤 S3，将六个光谱波段与物理先验通道 P 沿通道维拼接，得到 7 通道输入张量；对每个通道，按训练集统计的该通道第 1 百分位数 p01 与第 99 百分位数 p99 进行裁剪并线性缩放至 [0,1]；随后按保持长宽比的填充方式（letterbox）将张量上采样至检测器设定输入尺寸（如 1024×1024），使极小目标在浅层检测头对应特征图上占据足够的网格单元、落入该检测头响应区间。

步骤 S4，将归一化后的 7 通道张量输入卷积神经网络检测器（其网络结构参见图 5）。本实施例检测器为单阶段检测网络，其首层卷积的输入通道数设为 7，从而将六个光谱波段与物理先验通道在第一层即联合卷积；网络含分别对应不同下采样倍率的三个检测头，依次对应下采样 8 倍、16 倍、32 倍的特征图（P3/8、P4/16、P5/32）；颈部采用加权双向特征金字塔网络对多尺度特征进行带可学习权重的自顶向下与自底向上双向融合后再送入各检测头。检测器输出海洋漂浮垃圾的实例级边界框及对应置信度。

训练时，仅采用旋转与翻转等几何数据增强（例如旋转角度范围 ±180°、上下翻转概率 0.5、左右翻转概率 0.5），不采用拼接、混合、拷贝粘贴等会破坏多通道浮点输入的增强，亦不采用面向彩色图像的色彩抖动。

进一步地，对步骤 S4 输出的原始置信度 s 施加单调校准 p = sigmoid(a·logit(s)+b)；校准参数 a、b 在验证集上拟合（例如 a≈0.41、b≈−0.51），拟合后冻结，在测试与推理阶段不再改变。

在公开的 Sentinel-2 海洋漂浮垃圾基准、场景级划分的测试集上，本实施例对主要漂浮垃圾类别给出实例级检测结果；经上述校准，测试集置信度的期望校准误差由约 0.05 降至约 0.03，输出概率的可信度提升。

**实施例二（广义物理先验）**

将实施例一步骤 S2 中的物理先验通道替换为由浮游藻类指数 FAI 或塑料指数 PI 经归一化得到的通道，或替换为两种以上对漂浮物敏感的光谱指数的线性组合归一化结果，其余步骤与实施例一相同。本实施例用于说明物理先验通道不限于归一化水体指数反向映射这一种具体形式。
