## 一、发明名称

**一种融合水体物理先验通道的海洋漂浮垃圾多光谱检测方法、装置及存储介质**

---

## 二、技术领域

本发明涉及遥感图像处理与目标检测技术领域，具体涉及一种基于 Sentinel-2 多光谱卫星影像、融合水体物理光谱先验的海洋漂浮垃圾（海漂垃圾、塑料、藻类等漂浮物）自动检测方法、装置及计算机可读存储介质。

---

## 三、背景技术

### 3.1 现有技术

1. **光谱指数阈值法**：遥感领域已有针对水面漂浮物的物理光谱指数，如 NDWI（归一化水体指数）、FAI（浮游藻类指数）、PI（塑料指数）等。传统做法是对单像素计算指数值并设定阈值，将超过阈值的像素判为漂浮物。

2. **通用深度学习目标检测器**：YOLO、Faster R-CNN 等 CNN 检测器在自然图像（3 通道 RGB uint8）上表现优异，近年被尝试用于遥感目标检测。

### 3.2 现有技术的缺陷

1. **阈值法缺陷**：单像素光谱指数阈值法对噪声、薄云、太阳耀斑、海况变化极其敏感，无法给出目标级（实例级）的边界框，且固定阈值在不同场景下泛化能力差，虚警率高。

2. **通用检测器缺陷**：
   - 通用检测器面向 3 通道 RGB，无法直接利用 Sentinel-2 的多光谱信息（可见光 + 近红外 NIR + 短波红外 SWIR），而漂浮物的可分性恰恰主要体现在 NIR/SWIR 波段；
   - 海漂垃圾在卫星影像中**目标极小**（典型目标约 12–14 像素，部分小于 4 像素），且与海面背景对比度低，直接训练检测器召回率极低；
   - 检测器仅从原始光谱"自行学习"漂浮物可分性，未注入领域物理知识，在小样本、类别极不平衡条件下难以收敛到有效特征；
   - 检测器输出置信度严重失真（未校准），无法直接作为概率使用。

---

## 四、发明目的（要解决的技术问题）

针对海面漂浮目标"小、弱、样本少、类别不平衡、置信度失真"的难题，本发明要解决的技术问题是：

1. 如何构建一套能对 Sentinel-2 多光谱影像直接进行**实例级（边界框）**海面小目标漂浮垃圾检测的端到端方法（将水体物理光谱先验作为输入通道与原始波段联合送入 CNN，而非传统单像素阈值判别）；
2. 如何提供**可信（已校准）**的检测置信度输出。

## 五、技术方案

### 5.0 总体流程

```
Sentinel-2 L2A 多光谱瓦片 (6 波段: B4,B3,B2,B8,B11,B12)
        │
        ├─[模块A] 计算水体物理先验通道 (NDWI-inverse) ──► 第7通道
        │
        ▼
   7 通道张量 (6 光谱 + 1 物理先验)
        │
   [模块B] 通道归一化 (逐通道 p01/p99 分位裁剪+缩放)
        │
   [模块C] letterbox 上采样至检测器输入尺寸 (使小目标尺度落入 P3 检测头响应区间)
        │
   [模块D] 多通道 CNN 检测器 (可选 BiFPN 加权双向特征融合)
        │
   [模块E] 检测框 + 原始置信度
        │
   [模块F] Platt 校准 ──► 已校准概率 + 边界框  (最终输出)
```

### 5.1 模块A：水体物理先验通道的构造（核心创新点）

在原始 6 个光谱波段之外，**追加一个确定性的物理先验通道**作为检测网络的输入通道，该通道由光谱波段直接计算、**不依赖任何人工标注**，物理含义为"该像素属于水面漂浮物的先验可能性"。

优选实施：采用 **NDWI 反向指数（NDWI-inverse）** 构造先验通道 `P`：

```
NDWI = (Green − NIR) / (Green + NIR + ε)        # Green=B3, NIR=B8, ε=1e-6
P    = clip( (1 − NDWI) / 2 , 0, 1 )
```

物理依据：纯水体在 NIR 强吸收，NDWI 较高 → `P≈0`；漂浮物（塑料、藻类、泡沫）在 NIR 反射高于绿光，NDWI 为负 → `P>0.5`。由此 `P` 在漂浮物处取高值、纯水处取低值，构成像素级漂浮物先验。

广义实施（写入说明书以扩大保护）：先验通道 `P` 也可由其他对漂浮物敏感、且可由本发明 6 波段计算的光谱指数（FAI、PI 等）经归一化构造，或由其线性/非线性组合构造；本发明不限于 NDWI-inverse 这一种指数。**注意：FDI 需用到红边波段 B6，不在本发明 B4/B3/B2/B8/B11/B12 波段集内，故不纳入。**

**关键点**：`P` 是输入到 CNN 的**独立通道**，与原始光谱波段在第一层卷积处即被联合卷积、端到端学习，而非作为后处理阈值或独立分支——这区别于现有阈值法与并联分支法。

### 5.2 模块B：逐通道归一化

对 7 个通道分别按训练集统计的 p01/p99 分位数做裁剪与线性缩放至 [0,1]，分位数统计存于 `channel_stats_7ch.json`。该归一化对 float32 表面反射率输入是必要的（不同波段量纲差异大）。

### 5.3 模块C：letterbox 尺度对齐（注意：非提升传感器分辨率）

将 native 256×256 的瓦片经 letterbox 上采样至检测器输入尺寸（如 512 或 1024）。其作用是**使极小目标在特征图上占据足够多的网格单元、令目标尺度落入 P3/8 检测头的有效响应区间**，从而改善小目标召回；并非提高真实传感器分辨率。撰写权利要求时应表述为"使目标尺度匹配检测头响应区间"，避免"提高分辨率"等不当表述。

### 5.4 模块D：多通道检测主干与可选 BiFPN 融合

- 检测器为多通道输入 CNN（优选 YOLOv11n，首层卷积 `ch=7`），含 P3/8、P4/16、P5/32 三个检测头；
- 可选采用 **BiFPN 加权双向特征融合**替换标准 FPN/PAN 颈部，对多尺度特征加权双向融合（作为从属权利要求）。

### 5.5 模块F：Platt 输出置信度校准

检测器原始置信度严重低估且失真。采用 **Platt 缩放**对原始得分 `s` 做单调映射得到校准概率：

```
p_calibrated = sigmoid( a · logit(s) + b )    # a,b 由验证集拟合，测试集不再变动
```

参数在**验证集**拟合后冻结，直接应用于测试/推理集（避免数据泄漏）。

## 七、具体实施例

### 实施例1（完整 7 通道流程）

- 数据：MARIDA / Sentinel-2 L2A，native 256×256 float32 瓦片，6 波段 B4,B3,B2,B8,B11,B12；
- 先验：按 5.1 计算 NDWI-inverse 第 7 通道；
- 归一化：逐通道 p01/p99（见 `channel_stats_7ch.json`）；
- 检测器：YOLOv11n，`ch=7`，BiFPN 颈部，imgsz=1024（letterbox），三检测头 P3/P4/P5；
- 训练：仅几何增强（`degrees=180, flipud=0.5, fliplr=0.5`），禁用 mosaic/mixup/copy_paste 与 HSV 色彩抖动（多光谱非 RGB 色彩，色彩抖动无物理意义且破坏 float32 多通道输入）；
- 校准：验证集拟合 Platt 参数 a≈0.408, b≈−0.509，冻结后用于测试集。

### 实施例2（广义先验）

将第 7 通道替换为 FAI 或 PI 归一化指数，或多指数线性组合，其余同实施例1，用于说明先验通道不限于 NDWI-inverse 单一形式。

（装置与存储介质实施例对应权利要求 8、9，由处理器执行计算机程序实现各模块，从略。）

## 八、技术效果（系统级，整条 pipeline 端到端）

> 陈述口径：以下均为**完整方法（7 通道物理先验输入 + BiFPN 颈部 + imgsz=1024 letterbox + Platt 校准）在公开 MARIDA Sentinel-2 数据集 honest 场景级划分（scene-level split，无数据泄漏）测试集上的端到端表现**，不对单个组件作分项因果断言。

**1. 实例级检测能力（公开基准，可复现）**

| 指标 | 数值 | 设置 |
|---|---|---|
| Marine_Debris AP50 | **0.576–0.607** | 3-seed，imgsz=1024（BiFPN 0.576±0.045 / baseline 颈部 0.607±0.022） |
| mAP50（全类） | 0.342–0.350 | 3-seed，imgsz=1024 |
| Best F1（Marine_Debris） | 0.479 ± 0.037 | 3-seed，BiFPN@1024 |
| 部署工作点 F1（实例级，τ=0.25, IoU≥0.5） | **0.604**（P 0.581 / R 0.630） | seed-0，测试集 73 瓦片 / 108 个 Marine_Debris GT 实例 |

对比意义：海面漂浮垃圾目标尺寸仅约 12–14 像素（native 256 下接近亚像素），属于检测框架的极限小目标区间；本方法在该困难任务上给出可用的实例级（边界框）检测，而传统单像素光谱阈值法只能输出像素掩膜、无实例框。

**2. 置信度校准能力**

held-out 测试集期望校准误差 ECE 由 0.051 降至 0.029（验证集由 0.103 降至 0.029），使原本严重失真的检测置信度可作为概率使用。

> 说明（口径选择）：本节刻意以系统级端到端指标陈述技术效果，符合本领域专利惯例（如对比专利 CN117765421B、CN118842510A 亦以整体性能陈述作效果，不分项消融）。各组件（BiFPN/letterbox/Platt）在不同子配置下的取舍属内部研究记录，不构成本申请对外的分项效果主张。

## 九、创造性论证与规避现有技术建议（重要）

代理人/审查员预期会引用的现有技术及本发明的区别：

1. **NDWI / FAI / PI 等光谱指数（公知）**：现有技术将指数用于**单像素阈值判别**，输出二值掩膜、无目标级框、无学习。本发明将先验作为**CNN 端到端可学习的输入通道**，与原始波段联合卷积，输出实例级检测框——用途与机制不同。**独立权利要求应限定"作为多通道输入送入 CNN 检测器"，不要写成阈值判别。**

2. **BiFPN（Tan 2020，公知）/ Platt 校准（1999，公知）/ letterbox（公知）**：均为公知技术，**仅作从属权利要求**，不承担新颖性。

3. **新颖性与创造性的务实预判**：经初步检索（2026-06，Google Patents）未见"光谱指数作 CNN 额外输入通道做卫星海漂垃圾实例检测"的在先**专利**；但学术**文献**中"将 NDWI/FDI 等指数作为额外输入通道喂给 CNN/U-Net 做海漂垃圾检测"已属常见做法，权 1 存在创造性被质疑的可能。**本申请目的为资质用途（毕业/职称/结题），可接受"带病授权"风险。** 退守路线：若权 1 被驳，退到权 2（NDWI-inverse 具体式）+ 权 1 的"**实例级边界框检测**"区别点（多数海漂垃圾文献为像素分割，实例框检测较少见）。

4. **诚信性要求（务必遵守）**：第 7 通道必须使用**确定性、由光谱波段计算**的 NDWI-inverse 先验（`v1_make_physidx_tiles.py` 实现），**不得**使用历史版本中由真值标注派生的 oracle 热力图先验——后者在测试期泄漏真值、不可复现，写入专利将导致实施例不可重复、效果不可信。本交底书所有数据均基于确定性物理先验。
